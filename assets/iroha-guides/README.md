## 制作プロンプト仕様（要約）

共通: ゴルフ初心者向けウェブ教材の情景イラスト。自然な景色、明瞭な輪郭、親しみやすい描画。青いポロシャツ、白い帽子、ベージュのパンツ、白いゴルフシューズの成人男性。文字・ロゴ・透かしなし。ルールの厳密な距離や救済範囲を図示しない。

- preparation: 自宅で翌日のゴルフ道具を確認。ボール、ティー、グローブ、マーカー、フォーク、タオル、水筒をテーブルに並べ、バッグとシューズを近くに置く。
- dress: クラブハウス前に立つ全身像。青い襟付きポロ、ベージュのパンツ、ベルト、白い帽子とシューズ。軽い上着を持つ。全国共通の服装規定として断定しない。
- warmup: 練習場近くの安全な場所で穏やかなクロスボディの肩ストレッチ。両足を地面につける。ゴルフバッグを脇に置き、自然な人体と手の形。
- safety-wait: ティーイングエリアで、前方のフェアウェイにいる2人を見ながら待つ。クラブは地面に下ろした休止姿勢。打つ動作・素振りをしない。
- ready-clubs: カート道に停めたカートから球へ歩く。使いそうなアイアン3本をクラブヘッドを下にして持つ。カートは道から出さない。
